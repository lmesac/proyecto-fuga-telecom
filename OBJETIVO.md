# Objetivo del proyecto

Problema: priorizar revisión de clientes con riesgo de abandono en telecomunicaciones.
Usuario previsto: analista de atención y retención.
Objetivo analítico: comparar clasificadores de Churn simulado con variables disponibles antes de la baja, condición aún pendiente de verificar.
Éxito analítico: superar ROC-AUC 0,5 de baseline en validación y reportar estabilidad, precisión y recall. No se fija un objetivo después de observar test.
Éxito de negocio propuesto: evaluar captación de abandonos dentro del 20% de clientes priorizados; ahorro y retención requieren un experimento futuro, no se deducen de este CSV.
Alcance: ejercicio con datos sintéticos según el README del equipo; no demuestra utilidad sobre clientes reales. Riesgos pendientes: script original de generación, licencia y disponibilidad temporal de predictores. No prometer predicción futura a un plazo específico.
